# AI 外脑 Demo —— 有状态工作流（LangGraph）可选依赖
#
# 安装（推荐独立虚拟环境，理由见下）：
#     python -m venv .venv-langgraph --system-site-packages
#     .venv-langgraph\Scripts\python.exe -m pip install -r requirements-langgraph.txt
#
# 为什么不写进 requirements.txt：
#   1. LangGraph 不是运行主流程（Agent Loop / 会议分析 / 风险预警）的必需依赖；
#   2. 项目当前用 Python 3.14，LangGraph 生态在 3.14 上的可用组合需要被**锁死**，
#      否则 CI 与本机行为会不一致；
#   3. 不装它时 `aieb.workflow` 的导入会给出可操作的提示（见 aieb/workflow/__init__.py），
#      而不是在 import 阶段就炸掉整个应用。
#
# 以下版本是在 Python 3.14.2 / Windows 11 上**实测通过**的组合（46+ 工作流测试、
# 真实浏览器 E2E、40 场景对照实验均基于这一组版本）。

langgraph-checkpoint-sqlite==3.1.3
langchain-openai==1.7.4
aiosqlite>=0.22
